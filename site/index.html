What Lumen does differently

Three structural advantages over flat-rate single-platform competitors.

Cross-platform core

One Rust core, three platforms

macOS, Windows, and Linux share the same chunking, encryption, sync, and cache engine. Platform adapters are thin — no rewrite risk per OS, no version-lock to one vendor's newest release.

Deconstructed pricing

$3/mo + storage at cost + 10%

Bring your own bucket or use managed R2/B2/Storj. Storage passes through at provider cost plus a 10% operations margin — billing shrinks when GC reclaims space, it never ratchets up.

Agent-native

MCP server built in

Cursor, Claude, Codex-type agents call list_projects, search_files, read, and write tools directly. Files are a first-class API surface, not just Finder entries.

Built for agents first

A dedicated MCP server exposes your drive as structured tools. Agents search metadata locally — instant, offline-capable filename queries — and pull chunk ranges only when needed.
