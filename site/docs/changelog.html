Changelog

v0.1 beta

  • Rust workspace core: FastCDC content-defined chunking, per-chunk AES-256-GCM envelope encryption with HKDF-derived keys, prefetch engine with learning-based priority queue, ordered cursor sync changelog.
  • Storage adapters implementing one ObjectStore trait against Cloudflare R2, Backblaze B2, Storj, MinIO, and user-supplied S3 endpoints; LocalObjectStore for dogfooding and cross-process tests.
  • Unix FUSE shim (macOS/Linux) and Windows WinFsp shim sharing one MountOps layer; deferred deletes, DirMarker read_directory protocol on Windows.
  • MCP server: stdio + TCP transports, list/search (filename local, content opt-in), agent write path through CommitBatcher, authorize-gated JWT auth, gc_run tool with flush-first contract.
  • Axum API server: signup/login/me routes, ordered changes feed, Dodo Payments integration (Standard Webhooks verification, checkout sessions, metered usage events) — billing is Dodo, not Stripe.
  • Pricing architecture: $3/mo base plus storage at provider cost + 10% margin; BYOB mode at $3/mo flat at any volume. Mark-and-sweep GC with negative-delta billing reconciliation — reclaimed bytes reduce the metered amount.
  • 103 passing tests across the workspace including COGS regression gates pinning the multi-provider price curve.
